## AutomationExercise UI Automation Framework

A Hybrid UI Automation Framework built using **Java, Selenium WebDriver, TestNG, Maven, and Page Object Model (POM)** to automate end-to-end test scenarios on the AutomationExercise website.

🔹  Features
- **Hybrid Automation Framework**
- **Page Object Model (POM)**
- **TestNG Framework**
- **Maven Build Management**
- **PageFactory Implementation**
- **Explicit Waits**
- **JSON Data Provider**
- **Extent Reports**
- **TestNG Listeners**
- **Retry Mechanism for Failed Tests**
- **Reusable Components**
- **Cross-browser support**
- **Git & GitHub Version Control**
🛠️ Tech Stack
- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Maven**
- **Page Object Model (POM)**
- **PageFactory**
- **JSON**
- **Extent Reports**
- **Git**
- **GithHUB**

## Test Coverage
Automated end-to-end test scenarios including **User Registration, Login, Product Search, Product Details, Add to Cart, Cart Validation, Checkout, Payment, Contact Us, Subscription, Category Navigation, and Account Management**.

## Framework Highlights
- **Reusable Page Objects**
- **Centralized BaseTest**
- **Utility Methods**

- **TestNG Listeners**
